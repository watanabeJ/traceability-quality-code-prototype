# 测试问题回复：043c、Q6、Q7、Q9

## 043c　绑定审核显示几种当前绑定状态？

以运营端「绑定审核」原型为准。列表和筛选均保留 **待激活、未绑定、已激活、撤回申请中、部分撤回、已撤回** 六种状态。“全部状态”表示显示所有匹配记录。此次修订了说明书、页面需求说明和批注。

绑定申请待审核时显示“待激活”，驳回后显示“未绑定”，通过后通常显示“已激活”。若关联码段进入撤回流程，先看是否有待审批的撤回申请，有则显示“撤回申请中”。若本次申请的码段与随后获批的撤回单有交集，显示“已撤回”。其余情况查看关联激活记录，有效与已重置并存时显示“部分撤回”，全部已重置时显示“已撤回”。原申请的审核结论仍为“已通过”。

详见 [绑定审核页面需求说明](../../prototype-annotator/specs/current/P09-绑定审核.md)。

## Q6　客户管理导出的工作表叫什么？

从运营端「客户管理」导出的 `.xlsx` 文件包含一张工作表，标签名为 **客户列表**。导出包含当前筛选条件下所有分页的匹配客户。清空筛选后导出全部客户。

## Q7　客户列表导出哪些列，如何排序？

按客户管理页面从左到右的阅读顺序，固定导出以下 11 列。

`序号 → 客户名称 → 账号 → 联系电话 → 公司号 → 号码类型 → 状态 → 订单码量 → 已绑定 → 绑定申请中 → 待绑定`

序号从 1 连续编号。账号、联系电话、公司号写为文本，例如公司号 `00001` 打开后仍显示为 `00001`。序号和最后四项码量写为数值，可直接汇总。

详见 [客户管理页面需求说明](../../prototype-annotator/specs/current/P02-客户管理.md)。

## Q9　运营端客户详情如何查看客户的订单、已激活产品和码量汇总？

**原型和相关文档均已更新。** 运营端「客户管理 → 客户详情」在「客户完整资料」与「客户订单记录」之间新增了同级的「客户业务汇总」。第一行依次显示「订单数量」「已激活产品」，第二行依次显示「订单码量」「已绑定」「绑定申请中」「待绑定」。六项指标均直接显示数字。

订单数量与客户端「数据概览」采用相同口径，统计该客户全部未撤销订单，每笔订单计一次，含多个品类的订单也只计一次。四项码量汇总同一批订单。已激活产品统计该客户当前处于已激活状态的产品数。
