# 功能规则说明

## 1. 规则使用方式

- 每条规则使用稳定编号，需求、接口、测试用例和缺陷单应引用该编号。
- “必须”表示正式系统不可省略；“当前实现”表示原型已经具备；“落地要求”表示后端实现需要补足。
- 所有数量均为整数，所有码段均为闭区间，码段数量为 `结束序号 - 起始序号 + 1`。

## 2. 账号与登录

| 编号 | 规则 |
| --- | --- |
| ACC-001 | 运营端和客户端使用独立登录入口与账号集合。 |
| ACC-002 | 只有“启用”状态账号可以登录并执行端内操作。 |
| ACC-003 | 客户账号只能访问与自身 `customer_id` 关联的数据。 |
| ACC-004 | 新建客户必须填写客户名称、登录账号、联系电话、初始密码、营业执照和法人身份证。 |
| ACC-005 | 客户登录账号必须唯一；初始密码不少于 8 位。 |
| ACC-006 | 当前登录的运营账号不能禁用自身。 |
| ACC-007 | 修改密码必须校验当前密码；新密码不少于 8 位且同时包含字母和数字。 |
| ACC-008 | 禁用账号不删除历史业务数据，只禁止登录和新操作。 |
| ACC-009 | 客户营业执照和法人身份证仅支持图片或 PDF，单个文件最大 10 MB。 |

## 3. 库存码段生成

| 编号 | 规则 |
| --- | --- |
| QR-001 | 只有启用状态的运营账号可以生成库存码段。 |
| QR-002 | 单个批次生成数量为 `1–10,000,000`，必须为正整数。 |
| QR-003 | 二维码宽度和高度独立输入，范围均为 `8–300 mm`。 |
| QR-004 | 每次生成必须取得不重复的连续序列号范围。正式系统应由数据库或统一号段服务分配，不能依赖前端计算。 |
| QR-005 | 序列号由前缀和固定宽度数字组成；当前原型默认使用 `QR` 加 8 位数字。 |
| QR-006 | 生成成功后建立库存码段批次，初始计算状态为“未分配”。 |
| QR-007 | 页面在生成期间显示加载状态；正式系统应返回异步任务状态，而不是保持长连接等待全部图片完成。 |
| QR-008 | 二维码图形下方必须包含对应序列号，文件名也使用该序列号。 |
| QR-009 | 二维码内容指向扫码端单码地址，例如 `active.html?serial={serial}`；正式环境使用正式域名和签名策略。 |

## 4. 二维码压缩包

| 编号 | 规则 |
| --- | --- |
| PKG-001 | 支持“部分下载”和“下载完整压缩包”两个独立操作。 |
| PKG-002 | 部分下载从当前码段起始序号开始，只输入下载数量，不选择起始序号。 |
| PKG-003 | 部分下载数量必须为正整数且不得超过当前库存批次总量。业务上不另设固定上限，但后端可以基于资源情况转异步任务。 |
| PKG-004 | 完整下载不限制业务码量；大批量必须异步生成。 |
| PKG-005 | 实际压缩包至少包含 `codes/` 目录、`manifest.csv` 和 `README.txt`。 |
| PKG-006 | `codes/` 中每个二维码为独立文件，当前目标格式为 SVG。 |
| PKG-007 | `manifest.csv` 记录序列号、库存批次、分配状态、订单号和客户名称。 |
| PKG-008 | `README.txt` 记录完整码段范围、下载范围、数量、尺寸和包内容说明，不要求输出额外 `batch.json`。 |
| PKG-009 | 正式下载文件必须记录文件大小、摘要校验值、生成时间和过期时间。 |

## 5. 库存与码段分配

| 编号 | 规则 |
| --- | --- |
| INV-001 | 库存批次状态为派生值：已分配量为 0 时“未分配”；有剩余且有分配时“部分分配”；无剩余时“已分配”。 |
| INV-002 | 库存已分配量只统计状态不是“已撤销”的分配订单。 |
| INV-003 | 撤销分配后，原订单码段重新成为来源库存批次的空闲区间。 |
| ALLOC-001 | 只有运营端可以分配码段。 |
| ALLOC-002 | 只能分配给“启用”状态客户。 |
| ALLOC-003 | 必须从库存批次当前空闲的连续区间中分配。 |
| ALLOC-004 | 分配数量为正整数，且不得超过选中连续空闲区间的数量。 |
| ALLOC-005 | 分配范围默认从所选空闲区间起点连续截取。 |
| ALLOC-006 | 分配成功后生成一条分配订单，并记录来源库存批次、客户、码段、数量、备注、分配时间和操作人。 |
| ALLOC-007 | 分配动作本身不发送“客户获得新码段”站内信。 |
| ALLOC-008 | 同一库存批次内的有效分配订单码段不得重叠。 |

## 6. 撤销分配

| 编号 | 规则 |
| --- | --- |
| RECALL-001 | 撤销分配只用于整笔分配订单，不支持拆分撤销。 |
| RECALL-002 | 只有运营端可以执行，入口位于订单详情、客户详情或库存码段详情。 |
| RECALL-003 | 仅当订单已激活码量为 `0` 且绑定申请中码量为 `0` 时显示和允许操作。 |
| RECALL-004 | 撤销时必须填写原因。 |
| RECALL-005 | 撤销成功后订单状态变为“已撤销”，码段返回来源库存。 |
| RECALL-006 | 与该订单关联且未撤回的绑定申请统一转为“已撤回”。 |
| RECALL-007 | 与该订单关联的新建产品并绑定流程解除订单和申请码段关系；未激活产品恢复为草稿。 |
| RECALL-008 | 审核或绑定并发发生后，后端必须在同一事务中重新校验 RECALL-003，不能只依赖页面入口是否可见。 |

## 7. 订单数量口径与码段占用

| 编号 | 规则 |
| --- | --- |
| ORD-001 | `剩余可用 = 订单码量 - 已激活 - 绑定申请中`，最小为 0。 |
| ORD-002 | “已激活”按有效激活区间合并去重计算，不直接信任累计字段。 |
| ORD-003 | “绑定申请中”包括已有产品追加绑定的待审批申请，以及新建产品并绑定的待审核申请。 |
| ORD-004 | 草稿、已驳回、已通过、已撤回申请不计入绑定申请中；已通过部分由激活记录计入已激活。 |
| ORD-005 | 订单空闲范围应扣除有效激活范围和待审批申请范围。 |
| ORD-006 | 选择绑定范围时必须取得一段足够长的连续空闲区间，不能把多个离散区间拼成一次申请。 |
| ORD-007 | 已撤销分配的订单不在运营或客户订单台账中作为有效订单展示。 |

## 8. 产品资料

| 编号 | 规则 |
| --- | --- |
| PROD-001 | 产品按客户隔离，同一产品记录归属于一个客户。 |
| PROD-002 | 产品至少填写产品名称和产品批次后才能保存。 |
| PROD-003 | 新建产品绑定必须从一个本人有效且有剩余码量的订单发起。 |
| PROD-004 | 产品资料分为产品、企业、生产单位、质量、生产追溯五个模块。 |
| PROD-005 | 客户可以新增自定义字段；有内容的自定义字段必须填写字段名称。 |
| PROD-006 | 标准单文件字段最多 1 个文件，其他标准媒体字段及自定义媒体字段最多 10 个文件。 |
| PROD-007 | 客户可编辑草稿和已驳回内容；待审核内容只读；已激活产品可查看，并可在允许的业务入口继续编辑或追加绑定。 |
| PROD-008 | 运营端可在审核过程中编辑待审核或已激活产品资料，并保留操作审计。 |
| PROD-009 | 预览码使用当前编辑资料，不占用订单码量，也不计入扫码次数。 |
| PROD-010 | 产品所有有效激活码段均被重置后，当前实现将产品恢复为“草稿”并清空提交时间；正式开发应保持该规则或由产品再次确认。 |

## 9. 绑定申请与激活

| 编号 | 规则 |
| --- | --- |
| BIND-001 | 客户可选择“已有已激活产品追加绑定”或“新建产品并绑定”。 |
| BIND-002 | 已有产品追加绑定只能选择当前客户名下的已激活产品。 |
| BIND-003 | 申请数量必须为正整数且不超过订单剩余可用码量。 |
| BIND-004 | 同一订单、产品和产品批次不能同时存在重复的待审批追加绑定申请。 |
| BIND-005 | 申请提交时必须固化订单号、产品、批次、数量和具体连续码段。 |
| BIND-006 | 待审批申请占用对应码段，其他申请和直接绑定不得再使用。 |
| BIND-007 | 客户可撤回尚未处理的申请；撤回后不再占用码段。 |
| BIND-008 | 审核通过前必须重新校验客户、订单、产品状态、数量和码段可用性。 |
| BIND-009 | 审核通过后建立唯一激活记录，申请改为“已通过”，产品改为或保持“已激活”。 |
| BIND-010 | 审核驳回必须填写原因，申请改为“已驳回”并释放码段占用。 |
| BIND-011 | 客户可修改已驳回申请并重新提交；重新提交时再次计算并校验可用码段。 |
| BIND-012 | 运营端直接绑定仅可选择订单所属客户名下的已激活产品，并执行与审核通过相同的码段校验和激活写入。 |
| BIND-013 | 绑定审核结果状态与当前绑定状态分开保存或计算。审核“已通过”不因后续撤回而改写，当前绑定状态可变为“部分撤回”或“已撤回”。 |

## 10. 产品撤回与码段重置

| 编号 | 规则 |
| --- | --- |
| WD-001 | 产品撤回只能针对已存在的具体有效激活记录。 |
| WD-002 | 从订单绑定记录发起时只撤回当前单条订单码段，不显示多选。 |
| WD-003 | 从撤回申请页发起时可以勾选同一产品的一个或多个有效激活码段。 |
| WD-004 | 已重置码段和已有待审批撤回申请占用的码段不能重复选择。 |
| WD-005 | 撤回申请必须记录产品、批次、客户、码段明细、申请数量、原因和申请时间。 |
| WD-006 | 运营审核驳回必须填写原因，原激活关系和数量保持不变。 |
| WD-007 | 运营审核通过时，只重置申请中精确匹配的激活范围。 |
| WD-008 | 一个激活记录可被部分重置；正式后端应拆分区间或建立独立重置明细，不能丢失未重置部分。 |
| WD-009 | 通过后回滚订单已激活量、客户已激活量和产品有效码量，并记录实际回滚数量。 |
| WD-010 | 撤回通过不删除原绑定申请；原审核结果保留，激活记录进入“已重置”或产生重置明细。 |
| WD-011 | 绑定审核列表的当前绑定状态根据有效和已重置激活记录计算为“已激活、部分撤回、已撤回、撤回申请中”等。 |

## 11. 扫码展示

| 编号 | 规则 |
| --- | --- |
| SCAN-001 | 扫码端无需登录，通过单个序列号解析状态。 |
| SCAN-002 | 有效激活记录且其时间晚于最近一次相关重置时，显示已激活页面。 |
| SCAN-003 | 无有效新激活但存在已通过撤回产生的重置记录时，显示已重置页面。 |
| SCAN-004 | 不满足已激活或已重置条件时，显示未激活页面。 |
| SCAN-005 | 预览码和已激活页面顶部显示统一固定横幅；未激活和已重置页面维持独立状态样式。 |
| SCAN-006 | 已激活页面仅展示有内容的公开模块；产品大类和产品子类不在扫码端展示。 |
| SCAN-007 | 文本字段较多时默认展示前 5 项，可展开剩余内容；附件和图片仍按模块展示。 |
| SCAN-008 | 只有真实已激活单码访问计入扫码次数；预览码、未激活和已重置访问不计入。 |
| SCAN-009 | 扫码记录至少包含序列号、访问时间、总次数；正式系统应补充 IP、User-Agent、来源和防刷结果等可选信息。 |

## 12. 消息与通知

| 编号 | 规则 |
| --- | --- |
| MSG-001 | 码段分配给客户不生成站内信。 |
| MSG-002 | 绑定审核通过或驳回后通知对应客户。 |
| MSG-003 | 撤回审核通过或驳回后通知对应客户。 |
| MSG-004 | 客户端只看到本人业务结果消息，不展示申请提交类内部消息。 |
| MSG-005 | 消息包含类型、标题、正文、接收客户、发送时间和已读状态。 |
| MSG-006 | 业务状态修改与消息写入应在同一事务或可靠事件机制中完成，避免状态已变但通知丢失。 |

## 13. 列表、筛选和导出

| 编号 | 规则 |
| --- | --- |
| LIST-001 | 文本搜索、枚举筛选、日期范围和排序可以组合使用。 |
| LIST-002 | 分页总数和导出数据都基于当前筛选结果。 |
| LIST-003 | 切换筛选条件或每页条数后回到第一页。 |
| LIST-004 | 导出文件自动增加“序号”列。 |
| LIST-005 | 运营端可导出客户列表、码段库存、订单台账和产品审核列表；客户端可导出本人订单台账。 |
| LIST-006 | 订单号、码段和批次号在前后端传输时使用字符串，禁止转为数值。 |

## 14. 页面功能清单

| 页面 | 主要功能 | 查询与筛选 |
| --- | --- | --- |
| 客户列表 | 新建、编辑、启禁用、查看详情、分配码段、导出列表 | 客户名称、账号、电话、状态；码量排序 |
| 客户详情 | 查看资料和证照、查看分配订单、绑定产品、撤销分配、进入订单详情 | 订单号；订单码量和时间排序 |
| 生成码段 | 填写数量、尺寸、备注，预览，生成，部分下载，完整下载，分配客户 | 不适用 |
| 码段库存 | 查看库存批次、生成码段、分配客户、导出列表、进入库存详情 | 码段范围、生成日期、分配状态；数量排序 |
| 库存码段详情 | 查看批次信息、空闲范围和分配历史，继续分配，撤销符合条件的分配 | 客户、订单号、分配日期；数量排序 |
| 订单台账 | 查看有效分配订单、进入详情、直接绑定产品、导出台账 | 客户名称、订单号、分配日期；各码量排序 |
| 订单详情 | 查看订单数量口径和绑定记录，绑定产品，撤销分配 | 产品名称、批次、大类、审核状态、申请/处理日期 |
| 绑定审核 | 查看新建产品组合申请和追加绑定申请，审核、驳回、编辑产品资料 | 客户、订单、产品、批次、大类、审核状态、当前绑定状态、日期 |
| 绑定审核详情 | 核对五模块资料、订单、数量和码段，编辑资料，通过或驳回 | 不适用 |
| 撤回审核 | 查看撤回产品、具体码段和数量，通过或驳回 | 申请编号、产品、客户、状态、日期 |
| 运营账号管理 | 新建、编辑、启禁用、重置密码 | 姓名、账号、状态、最近登录时间 |
| 站内信 | 查看业务结果通知、筛选、已读和删除 | 标题、内容、接收方、类型、阅读状态、日期 |
| 个人设置 | 修改当前账号密码 | 不适用 |

### 14.2 客户端

| 页面 | 主要功能 | 查询与筛选 |
| --- | --- | --- |
| 数据概览 | 查看本人码量摘要、最近申请动态，跳转对应业务记录 | 最近动态最多 5 条，不显示时间 |
| 订单台账 | 查看本人有效订单、进入详情、发起绑定、导出台账 | 日期及码量排序 |

| 产品编辑 | 维护五模块标准字段、自定义字段、图片和附件，保存草稿，预览码，提交审核 | 不适用 |

### 14.3 扫码端

| 页面 | 功能 |
| --- | --- |
| 预览码 | 展示当前编辑资料和固定横幅，不占码量、不计扫码次数 |
| 已激活 | 展示固定横幅、产品名称、序列号、查询次数和有内容的公开五模块资料 |
| 未激活 | 展示该码尚未关联有效产品的信息 |
| 已重置 | 展示原产品关系已撤回、当前为空白状态的信息 |
