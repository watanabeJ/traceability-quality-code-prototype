# 页面批注与需求说明

`annotations.json` 保存当前页面和局部批注。`page-map.json` 保存页面映射，`runtime/` 提供展示组件。

页面需求说明统一维护在 `specs/current/`，使用“页面编号-中文页面名称.md”命名。`specs/registry.json` 登记页面、路由和文档路径。页面内的需求说明与 P 批注直接读取这些文件。

通过项目的 `启动原型.cmd` 或 `python scripts/serve-system-docs.py` 启动服务后，可以查看和保存批注及需求说明，无需项目外部工具包。普通静态服务可以展示内容，不能回写编辑。

交付目录只包含当前资料。后续手工保存时，服务会按需生成编辑记录与修改前快照；这些新记录不进入下次导出的原型包。

当前页面目录见[页面需求说明](specs/README.md)。
