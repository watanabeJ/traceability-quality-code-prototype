## 02 页面业务说明

### 页面目标

查看本企业有效分配订单和码量使用情况，并进入产品绑定流程。

### 业务场景

码段分配后形成订单，后续产品绑定、激活、撤回和剩余可用量均以订单及其连续码段为基础。

- 按日期筛选和码量排序
- 进入订单详情
- 申请绑定已有产品
- 新建产品并绑定

## 05 业务规则

### 数据校验规则

- 仅展示当前客户且未撤销的订单

### 计算规则

- 剩余码量不足时不得提交绑定申请
- 剩余可用为 0 时禁用新绑定

### 操作规则

- 未选择其他排序条件时，列表默认按分配时间倒序排列，最新记录在前；用户主动选择排序后按所选规则执行。
- 待审批占用量变化后列表即时重算
- 按日期筛选和码量排序
- 新建产品并绑定
- 进入订单详情
- 申请绑定已有产品
- 导出本人订单台账
- 不展示客户名称、分配状态和运营操作人
- 导出仅包含当前客户和筛选结果
- 没有订单时显示空状态

### 数据一致性规则

- 不会看到其他客户订单
- 列表数量与订单详情一致
- 绑定入口仅在业务条件满足时可用
- 页面数据以后端当前有效业务关系为准，关联页面使用同一数据口径。

## 06 状态管理

### 状态定义

| 状态 | 定义 |
| --- | --- |
| 有效 | 订单码段可用于绑定 |
| 部分占用 | 存在激活或待审批绑定 |
| 无剩余 | 全部码量已占用 |
| 已撤销 | 整笔分配已撤销 |

### 状态转换图

```mermaid
stateDiagram-v2
  state "有效" as valid
  state "部分占用" as occupied
  state "无剩余" as exhausted
  state "已撤销" as recalled
  [*] --> valid: 分配成功
  valid --> occupied: 提交绑定或激活
  occupied --> exhausted: 剩余量归零
  occupied --> valid: 驳回或撤回占用
  valid --> recalled: 撤销分配
```

### 转换条件

| 当前状态 | 目标状态 | 转换条件 |
| --- | --- | --- |
| 初始 | 有效 | 分配成功 |
| 有效 | 部分占用 | 提交绑定或激活 |
| 部分占用 | 无剩余 | 剩余量归零 |
| 部分占用 | 有效 | 驳回或撤回占用 |
| 有效 | 已撤销 | 撤销分配 |

### 禁止转换

- 状态转换图中未定义的转换一律禁止。
- 前端不得直接指定目标状态，后端必须根据当前状态和业务条件执行转换。
- 后续业务过程不得覆盖历史审核或操作状态。

## 07 权限管理

### 页面权限

- 仅当前登录客户账号可访问。

### 操作权限

- 操作权限按当前账号状态、数据权限和业务前置条件判断；本页涉及：按日期筛选和码量排序、新建产品并绑定、进入订单详情、申请绑定已有产品、导出本人订单台账。

### 数据权限

- 仅允许访问当前 customer_id 名下的数据；前端筛选不能替代后端数据权限校验。

## 09 异常与边界

### 重复操作

- 写操作必须携带客户端请求标识并保证幂等；重复提交不得重复创建记录、扣减数量或发送通知。

### 并发处理

- 后端在提交时重新校验记录版本、当前状态及数量；发生冲突时拒绝本次操作并返回最新数据。

### 超时处理

- 请求超时时保留当前查询或表单上下文，不得预先写入成功状态；重试时沿用原幂等标识。

### 数据异常

- 查询成功但无记录时展示明确空状态，保留可用的新增、返回或重试入口。
- 未登录、账号禁用、越权访问或数据不属于当前主体时终止操作，并返回无权限或安全的空结果。
