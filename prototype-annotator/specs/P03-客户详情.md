## 02 页面业务说明

### 页面目标

查看单个客户的完整资料、证照和分配订单，并在客户上下文内处理绑定或撤销分配。

### 业务场景

运营人员需要维护客户主体、登录账号和证照资料，并从客户维度追踪订单及码量使用情况。

- 查看可点击的证照附件
- 搜索和排序客户订单
- 进入订单详情
- 为订单绑定产品

## 05 业务规则

### 数据校验规则

- 仅展示当前客户的数据
- 撤销分配要求订单已激活和绑定申请中数量均为 0
- 撤销分配必须填写原因且整单执行
- 客户不存在时提示并提供返回客户列表入口
- 不满足撤销条件时不展示撤销操作

### 操作规则

- 未选择其他排序条件时，列表默认按分配时间倒序排列，最新记录在前；用户主动选择排序后按所选规则执行。
- 搜索和排序客户订单
- 查看可点击的证照附件
- 进入订单详情
- 为订单绑定产品
- 在满足条件时撤销分配
- 已撤销订单不作为有效订单展示

### 数据一致性规则

- 客户资料与客户列表相同记录一致
- 从订单详情返回时保留客户详情来源
- 撤销操作条件与库存详情一致
- 页面数据以后端当前有效业务关系为准，关联页面使用同一数据口径。

## 06 状态管理

### 状态定义

| 状态 | 定义 |
| --- | --- |
| 有效 | 订单码段可用于绑定 |
| 部分占用 | 存在激活或待审批绑定 |
| 无剩余 | 全部码量已占用 |
| 已撤销 | 整笔分配已撤销 |

### 状态转换图

```mermaid
stateDiagram-v2
  state "有效" as valid
  state "部分占用" as occupied
  state "无剩余" as exhausted
  state "已撤销" as recalled
  [*] --> valid: 分配成功
  valid --> occupied: 提交绑定或激活
  occupied --> exhausted: 剩余量归零
  occupied --> valid: 驳回或撤回占用
  valid --> recalled: 撤销分配
```

### 转换条件

| 当前状态 | 目标状态 | 转换条件 |
| --- | --- | --- |
| 初始 | 有效 | 分配成功 |
| 有效 | 部分占用 | 提交绑定或激活 |
| 部分占用 | 无剩余 | 剩余量归零 |
| 部分占用 | 有效 | 驳回或撤回占用 |
| 有效 | 已撤销 | 撤销分配 |

### 禁止转换

- 状态转换图中未定义的转换一律禁止。
- 前端不得直接指定目标状态，后端必须根据当前状态和业务条件执行转换。
- 后续业务过程不得覆盖历史审核或操作状态。

## 07 权限管理

### 页面权限

- 仅启用状态的运营人员可访问。

### 操作权限

- 操作权限按当前账号状态、数据权限和业务前置条件判断；本页涉及：搜索和排序客户订单、查看可点击的证照附件、进入订单详情、为订单绑定产品、在满足条件时撤销分配。

### 数据权限

- 运营端可访问平台业务数据；涉及账号管理、审核和撤销的操作必须记录操作人及时间。

## 09 异常与边界

### 重复操作

- 写操作必须携带客户端请求标识并保证幂等；重复提交不得重复创建记录、扣减数量或发送通知。

### 并发处理

- 后端在提交时重新校验记录版本、当前状态及数量；发生冲突时拒绝本次操作并返回最新数据。

### 超时处理

- 请求超时时保留当前查询或表单上下文，不得预先写入成功状态；重试时沿用原幂等标识。

### 数据异常

- 查询成功但无记录时展示明确空状态，保留可用的新增、返回或重试入口。
- 未登录、账号禁用、越权访问或数据不属于当前主体时终止操作，并返回无权限或安全的空结果。
- 客户不存在时提示并提供返回客户列表入口
