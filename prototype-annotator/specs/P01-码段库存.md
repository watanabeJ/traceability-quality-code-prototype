## 02 页面业务说明

### 页面目标

集中查看平台生成的库存码段批次、剩余可用量和分配进度，并从库存维度发起生成、分配和导出操作。

### 业务场景

平台先统一生成连续二维码库存，再按客户需求分配。页面需要保证库存数量、空闲区间和分配记录使用同一数据口径。

- 按码段范围、生成日期和分配状态组合筛选
- 按数量字段排序并分页查看
- 进入库存码段详情
- 从可用库存发起分配

### 业务对象

| 业务对象 | 页面内职责 | 数据来源与落地要求 |
| --- | --- | --- |
| 库存码段批次 | 页面初始化、关联查询或状态计算 | 当前原型为 localStorage / 页面上下文；正式接口待后端契约确认 |
| 分配订单 | 页面初始化、关联查询或状态计算 | 当前原型为 localStorage / 页面上下文；正式接口待后端契约确认 |

## 05 业务规则

### 数据校验规则

- 只有存在连续空闲范围时才能发起分配
- 导出范围与当前筛选结果一致
- 按码段范围、生成日期和分配状态组合筛选

### 计算规则

- 库存状态由已分配量和剩余量派生，不允许手工修改
- 已撤销分配的数量应回到来源库存批次

### 操作规则

- 未选择其他排序条件时，列表默认按生成时间倒序排列，最新记录在前；用户主动选择排序后按所选规则执行。
- 导出当前筛选结果
- 从可用库存发起分配
- 跳转生成码段
- 进入库存码段详情
- 无库存时展示空状态和生成入口
- 批次无连续可用码段时禁用分配
- 筛选无结果时保留筛选条件并展示无结果状态
- 按数量字段排序并分页查看
- 筛选、排序、分页和导出可组合使用

### 数据一致性规则

- 列表数量、状态与库存详情计算一致
- 分配和撤销后刷新可见最新库存结果
- 页面数据以后端当前有效业务关系为准，关联页面使用同一数据口径。

## 06 状态管理

### 状态定义

| 状态 | 定义 |
| --- | --- |
| 未分配 | 已分配数量为 0 |
| 部分分配 | 已分配数量大于 0 且仍有剩余 |
| 已分配 | 剩余可用数量为 0 |

### 状态转换图

```mermaid
stateDiagram-v2
  state "未分配" as unallocated
  state "部分分配" as partial
  state "已分配" as allocated
  [*] --> unallocated: 生成成功
  unallocated --> partial: 部分分配
  partial --> allocated: 分配完毕
  allocated --> partial: 撤销一笔分配
  partial --> unallocated: 撤销全部分配
```

### 转换条件

| 当前状态 | 目标状态 | 转换条件 |
| --- | --- | --- |
| 初始 | 未分配 | 生成成功 |
| 未分配 | 部分分配 | 部分分配 |
| 部分分配 | 已分配 | 分配完毕 |
| 已分配 | 部分分配 | 撤销一笔分配 |
| 部分分配 | 未分配 | 撤销全部分配 |

### 禁止转换

- 状态转换图中未定义的转换一律禁止。
- 前端不得直接指定目标状态，后端必须根据当前状态和业务条件执行转换。
- 后续业务过程不得覆盖历史审核或操作状态。

## 09 异常与边界

### 重复操作

- 写操作必须携带客户端请求标识并保证幂等；重复提交不得重复创建记录、扣减数量或发送通知。

### 并发处理

- 后端在提交时重新校验记录版本、当前状态及数量；发生冲突时拒绝本次操作并返回最新数据。

### 超时处理

- 请求超时时保留当前查询或表单上下文，不得预先写入成功状态；重试时沿用原幂等标识。

### 数据异常

- 查询成功但无记录时展示明确空状态，保留可用的新增、返回或重试入口。
- 未登录、账号禁用、越权访问或数据不属于当前主体时终止操作，并返回无权限或安全的空结果。
