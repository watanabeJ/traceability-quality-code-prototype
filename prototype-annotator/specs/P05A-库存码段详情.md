## 02 页面业务说明

### 页面目标

查看单个库存批次的生成信息、可用区间和全部分配记录，并继续分配或撤销符合条件的分配。

### 业务场景

平台先统一生成连续二维码库存，再按客户需求分配。页面需要保证库存数量、空闲区间和分配记录使用同一数据口径。

- 查看库存摘要和空闲连续区间
- 搜索、筛选和排序分配记录
- 继续给客户分配码段
- 进入订单详情

## 05 业务规则

### 数据校验规则

- 一笔分配只能整单撤销
- 不满足条件时不展示撤销操作
- 批次不存在时提供返回库存列表入口

### 操作规则

- 未选择其他排序条件时，列表默认按分配时间倒序排列，最新记录在前；用户主动选择排序后按所选规则执行。
- 搜索、筛选和排序分配记录
- 继续给客户分配码段
- 查看库存摘要和空闲连续区间
- 进入订单详情
- 对符合条件的记录撤销分配
- 撤销分配仅在已激活和绑定申请中均为 0 时提供
- 撤销后码段回到本库存批次并参与空闲区间合并
- 没有分配记录时仍展示库存摘要和分配入口

### 数据一致性规则

- 分配历史与客户详情、订单台账一致
- 撤销后库存数量和空闲范围即时恢复
- 页面数据以后端当前有效业务关系为准，关联页面使用同一数据口径。

## 06 状态管理

### 状态定义

| 状态 | 定义 |
| --- | --- |
| 有效 | 订单码段可用于绑定 |
| 部分占用 | 存在激活或待审批绑定 |
| 无剩余 | 全部码量已占用 |
| 已撤销 | 整笔分配已撤销 |

### 状态转换图

```mermaid
stateDiagram-v2
  state "有效" as valid
  state "部分占用" as occupied
  state "无剩余" as exhausted
  state "已撤销" as recalled
  [*] --> valid: 分配成功
  valid --> occupied: 提交绑定或激活
  occupied --> exhausted: 剩余量归零
  occupied --> valid: 驳回或撤回占用
  valid --> recalled: 撤销分配
```

### 转换条件

| 当前状态 | 目标状态 | 转换条件 |
| --- | --- | --- |
| 初始 | 有效 | 分配成功 |
| 有效 | 部分占用 | 提交绑定或激活 |
| 部分占用 | 无剩余 | 剩余量归零 |
| 部分占用 | 有效 | 驳回或撤回占用 |
| 有效 | 已撤销 | 撤销分配 |

### 禁止转换

- 状态转换图中未定义的转换一律禁止。
- 前端不得直接指定目标状态，后端必须根据当前状态和业务条件执行转换。
- 后续业务过程不得覆盖历史审核或操作状态。

## 07 权限管理

### 页面权限

- 仅启用状态的运营人员可访问。

### 操作权限

- 操作权限按当前账号状态、数据权限和业务前置条件判断；本页涉及：搜索、筛选和排序分配记录、继续给客户分配码段、查看库存摘要和空闲连续区间、进入订单详情、对符合条件的记录撤销分配。

### 数据权限

- 运营端可访问平台业务数据；涉及账号管理、审核和撤销的操作必须记录操作人及时间。

## 09 异常与边界

### 重复操作

- 写操作必须携带客户端请求标识并保证幂等；重复提交不得重复创建记录、扣减数量或发送通知。

### 并发处理

- 后端在提交时重新校验记录版本、当前状态及数量；发生冲突时拒绝本次操作并返回最新数据。

### 超时处理

- 请求超时时保留当前查询或表单上下文，不得预先写入成功状态；重试时沿用原幂等标识。

### 数据异常

- 查询成功但无记录时展示明确空状态，保留可用的新增、返回或重试入口。
- 未登录、账号禁用、越权访问或数据不属于当前主体时终止操作，并返回无权限或安全的空结果。
- 批次不存在时提供返回库存列表入口
